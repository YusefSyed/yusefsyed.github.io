About

My work checks AI agents against records instead of their own reports. ToolEffectBench scores an agent by what it changed in a sandbox's database. Scopehaven judges an agent from the app's own records. effect-tracer signs what a Linux process tree did into a hash chain.

I started Scopehaven in October 2026 and work on it solo. It is pre-revenue. I am also a first-year student at the University of Toronto, with an intended double major in Math and CS.

I build with AI coding agents that I direct and review. I publish the results that don't flatter my own tools too: one of my two papers is a null result, and in Agent Eval Mutation Lab I withheld improvement claims after five of six validity gates failed.

Work

ToolEffectBench

Python, Inspect AI, Docker

A benchmark that scores prompt injection on tool-using LLM agents by what the agent changed in a network-less sandbox's database, not by its transcript.

17 models, 5,628 scored runs. On one task agents made 97 forbidden publish actions with no instruction to obey. Their final reports denied at least 13, and a final-state-only check missed 10 that a later revoke undid.

ToolEffectBench on GitHub ToolEffectBench paper

Scopehaven

Node.js. Open edition v0.7.0, Apache-2.0

A CLI and GitHub Action that catches an AI agent acting on the wrong account, tenant or refund, judged from the app's own records.

On its own synthetic test app, the vulnerable build fails 26 of 44 checks and the repaired build passes 44 of 44.

scopehaven.dev Scopehaven open edition on GitHub

effect-tracer

Rust, Linux ptrace/seccomp, Ed25519

Signs a process tree's file writes, connects, DNS and execs into a hash chain.

Caught 19 of 20 seeded bypasses at 1.1 to 1.9x overhead.

Papers

ToolEffectBench: Scoring Prompt Injection on Tool-Using Agents from Persisted State

Yusef Syed, sole author. Zenodo, 2026. DOI 10.5281/zenodo.23966727. arXiv submission in review.

Scores prompt injection on tool-using LLM agents by what the agent changed in a network-less sandbox's database, not by its transcript. 17 models, 5,628 scored runs.

Checks for Checkers: Sealed Paired Comparisons of AI Agent Verification Tools

Yusef Syed, sole author. Zenodo, 2026. DOI 10.5281/zenodo.23966747.

A blind, timestamped comparison on 96 planted-defect and 96 clean cases. My own tool caught 83 and an open-source framework caught 88, with no false alarms (p = 0.30). Published as a null result.
